# Переписка Эрдмана и Степановой
Я собрал датасет по книге из задания. Регулярными выражениями выделил письма, удалил воспоминания, сноски и переносы строк. Авторов определил по подписям и обращениям. С помощью pymorphy3 привёл слова к начальной форме и убрал пунктуацию.

В таблице есть дата, автор, текст письма, лемматизированный текст и количество слов. Полные даты записал в формате YYYY-MM-DD, неполные — YYYY-MM или YYYY. Пропущенный год по возможности восстановил по соседним письмам, неизвестные даты оставил пустыми.

Получилось 78 записей: 47 от Эрдмана и 31 от Степановой, включая записки и телеграммы. Один фрагмент с неясной границей выделил отдельно. Результат сохранил в letters.csv.
